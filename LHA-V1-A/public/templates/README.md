# Nexia Virtual Desk - Source Template PDFs

This directory is designated for storing the three Kerala Legal Heirship Certificate application reference PDFs:

1. `1-Main application LH.pdf` (Main Application Form LH-01 addressed to the Tahsildar)
2. `2-application -Legal heir.pdf` (Schedule of Legal Heirs LH-02 with Joint Declaration)
3. `3-LH-Witness.pdf` (Independent Local Witnesses Deposition LH-03 before Village Officer)

## Automated Fallback & High-Fidelity Client-Side Reproduction

The application includes high-fidelity print-ready layouts of all three forms with:
- Authentic Kerala Revenue Department Malayalam headings
- Standard ₹5 Court Fee Stamp box
- Dynamic multiple legal heir rows
- Independent dual-witness deposition statement
- Blank dedicated handwritten signature areas
- Automatic uppercase conversion for English text
- Zero distortion of Malayalam unicode characters
